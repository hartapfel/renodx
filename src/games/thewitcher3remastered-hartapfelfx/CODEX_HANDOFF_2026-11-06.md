## Prior source caveat

The current aerial model fades cloud opacity by foreground-air transmission as an approximation. The presentation's desired split is `cloud radiance*T(depth) + opacity*air in-scattering(depth) + (1-opacity)*background sky`. The Witcher's native fog color is an artistic full-sky blend and an earlier direct substitution visibly washed out cloud structure. Exact sky in-scattering is still unproven, so the candidate deliberately limits correction to measured additive sun emission.
