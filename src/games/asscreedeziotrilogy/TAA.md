# TAA moved to a separate addon

Ezio Trilogy TAA now lives in [asscreedeziotrilogy-taa](../asscreedeziotrilogy-taa/README.md).
Install its `.addon32` alongside the current Ezio Trilogy addon for HDR + TAA,
or use it alone with ReShade for native SDR. Embedded TAA is removed here.

- [Current implementation and porting guide](../asscreedeziotrilogy-taa/IMPLEMENTATION.md)
- [Preserved development history](../asscreedeziotrilogy-taa/DEVELOPMENT_HISTORY.md)

Do not combine the standalone addon with an older Ezio build containing TAA.
